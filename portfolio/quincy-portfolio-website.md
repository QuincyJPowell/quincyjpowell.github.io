Building My Personal Portfolio Website

Overview

This portfolio website was designed and developed to serve two purposes.

First, it provides a professional home for my projects, writing, resume, and academic work. Second, the website itself serves as a portfolio piece demonstrating my understanding of search engine optimization, information architecture, accessibility, responsive design, and user-centered content strategy.

Rather than relying on a website builder or template-heavy solution, I chose to build the site using Jekyll, GitHub Pages, Markdown, and custom SCSS to better understand the underlying structure of a modern static website.

⸻

Project Goals

From the beginning, I established several objectives.

* Create a professional online presence that feels approachable and authentic.
* Demonstrate SEO best practices through the site’s structure and content.
* Build a fully responsive website that works well on desktop and mobile devices.
* Meet modern accessibility standards wherever possible.
* Create a flexible system that can continue growing throughout my career.

⸻

Research & Inspiration

Before writing any code, I explored a variety of personal portfolio websites, agency websites, and editorial publications.

One of the strongest design influences was The Everygirl. I admired its clean typography, generous whitespace, strong editorial hierarchy, and welcoming visual style.

Rather than copying the design directly, I adapted those ideas into a visual identity that blends professional presentation with a warm, cottagecore-inspired aesthetic through soft colors, serif headings, rounded cards, and subtle visual details.

⸻

Information Architecture

One of the earliest design decisions involved organizing content in a way that would be intuitive for both visitors and search engines.

The final navigation includes:

* Home
* About
* Portfolio
* Writing
* Resume
* Curriculum Vitae
* Contact

Instead of placing every project on a single page, I organized my work into dedicated categories such as SEO, marketing, web projects, and academic work. This creates clearer navigation while also reinforcing topical organization.

Similarly, the Writing section separates professional, academic, and personal writing to support both user discovery and topical authority.

⸻

SEO Strategy

This website was planned with search engine optimization in mind from the beginning.

Key considerations include:

* Clear page hierarchy
* Descriptive page titles
* Individual page descriptions
* Logical internal linking
* Topic-based organization
* Human-readable URLs
* Semantic heading structure
* Content organized around user intent

Rather than treating SEO as a checklist completed after launch, the site’s architecture was intentionally designed to support discoverability from the earliest planning stages.

⸻

Accessibility

Accessibility was considered throughout the design process.

Current accessibility efforts include:

* High-contrast color combinations
* Consistent heading hierarchy
* Keyboard focus styling
* Responsive layouts
* Descriptive navigation
* Readable typography
* Sufficient spacing between interface elements

Future improvements will include expanded testing with accessibility evaluation tools and additional semantic enhancements.

⸻

Technical Implementation

The website is built using:

* Jekyll
* GitHub Pages
* Markdown
* HTML
* SCSS
* Git
* GitHub

Using a static site generator provides fast loading times, straightforward version control, and complete control over the site’s structure without unnecessary complexity.

⸻

Challenges

Several aspects of the project required iterative problem solving.

Examples include:

* Customizing the Minima theme while preserving maintainability.
* Building a responsive navigation system that worked consistently across desktop and mobile devices.
* Creating reusable card layouts for portfolio and writing sections.
* Organizing content into a structure that balances usability with SEO considerations.

Each challenge reinforced the importance of testing changes incrementally and documenting decisions throughout development.

⸻

Lessons Learned

This project strengthened my understanding of how design, development, content strategy, accessibility, and SEO work together.

Perhaps the most valuable lesson was recognizing that a website’s structure communicates as much as its content. Every navigation choice, heading, internal link, and page organization decision contributes to both the visitor experience and how search engines understand the site.

The project continues to evolve as I expand my portfolio and deepen my understanding of digital strategy.
